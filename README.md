# FinFamily Cloud

Веб-приложение для двух участников семьи с авторизацией, общим семейным пространством, облачным хранением операций и процентами на круговой диаграмме. Валюта: BYN (белорусский рубль).

## Что реализовано

- Регистрация и вход по email/паролю через Supabase Auth.
- Первый пользователь создаёт семейное пространство.
- Второй пользователь регистрируется отдельно и присоединяется по коду семьи.
- На одну семью ограничено два участника (проверка в SQL RPC).
- Доходы учитываются в балансе после отметки «Получено».
- Расходы уменьшают баланс только после отметки «Оплачено».
- Операции хранятся в Supabase Postgres.
- Realtime подписка обновляет список операций на подключённых устройствах.
- Круговая диаграмма выводит название категории и процент от суммы оплаченных расходов.

## Требования

- Node.js 20+
- Проект Supabase (бесплатного тарифа достаточно для старта)

## Настройка Supabase

1. Создайте проект на https://supabase.com.
2. В SQL Editor выполните весь файл `supabase/schema.sql`.
3. В Authentication → Providers включите Email.
4. Для быстрого тестирования можно отключить Confirm email. Для реального использования лучше оставить подтверждение почты включённым.
5. В Project Settings → API скопируйте Project URL и anon/public key.

## Запуск

```bash
npm install
cp .env.example .env.local
```

Заполните `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Затем:

```bash
npm run dev
```

Откройте http://localhost:3000.

## Как подключить второго участника

1. Первый пользователь регистрируется и входит.
2. В блоке настройки семьи вводит своё имя и создаёт семью.
3. После создания семейного профиля код приглашения отображается в блоке «Участники семьи» и копируется кнопкой.
4. Второй пользователь регистрирует собственный аккаунт, входит, вводит своё имя и этот код.
5. Оба пользователя увидят общие операции. Realtime обновляет список при изменениях.

Для публичного запуска рекомендуется добавить срок действия кода и безопасную ротацию приглашения.

## Публикация

Можно развернуть проект на Vercel:
1. Загрузите папку проекта в GitHub.
2. Импортируйте репозиторий в Vercel.
3. Добавьте две переменные окружения Supabase из `.env.local`.
4. Нажмите Deploy.

## Важные замечания перед production

- Это стартовый проект, а не уже развёрнутый сервис. Для облачного хранения необходимо создать Supabase-проект и задать ключи.
- Не помещайте `service_role` key в браузер или `.env` с префиксом `NEXT_PUBLIC_`.
- Перед публичным использованием проверьте RLS-политики, добавьте подтверждение email, восстановление пароля и аудит изменений.
- На текущем этапе семейный код читается из Supabase Table Editor; полноценная выдача invite code через безопасную RPC-функцию — рекомендуемое следующее улучшение.
- Лимиты, кредиты, накопления и экспорт Excel из предыдущего прототипа не включены в эту облачную стартовую сборку. Их можно подключить к той же базе следующими таблицами и экранами.
